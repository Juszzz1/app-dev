# The Twilight Saga Eclipse 

**Genre:** Romantic, fantasy, Adventure
**Platform:** Netflix

# Summary 
A vengeful vampire named Victoria builds an army of **newborn vampires** to attack Forks and kill Bella. Meanwhile, 
Bella is torn in a love triangle between Edward and Jacob, ultimately choosing Edward and getting engaged.
The Cullens and the wolf pack unite to destroy Victoria's army

# Main Characters
1. Bella Swan
2. Edward Cullen
3. Jacob Black
